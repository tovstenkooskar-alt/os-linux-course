# Файлы, маски, поиск и справка · шпаргалка

ФИО: Товстенко Оскар

Дата: 25.10.2026

Безопасные примеры выполнены в `~/files-lab` (каталог `cheat` и сам набор `inbox`). Опасные варианты в системе не запускались.

| Команда | Назначение | Безопасный пример | Опасный вариант и чем он опасен |
|---|---|---|---|
| `mkdir -p` | Создаёт каталог вместе с недостающими родителями и не ругается, если он уже есть | `mkdir -p ~/files-lab/cheat/sub` | `mkdir ~/files-lab/cheat/sub` без `-p` падает, если родителя ещё нет |
| `touch` | Создаёт пустой файл или обновляет время изменения | `touch ~/files-lab/cheat/note.txt` | `touch` с чужим путём затирает метку времени не того файла |
| `ls -A` | Показывает имена, включая скрытые, кроме `.` и `..` | `ls -A ~/files-lab/inbox` | `ls` без `-A` прячет `.settings`, его легко не заметить перед удалением |
| `cp` | Копирует файл, оригинал остаётся | `cp ~/files-lab/cheat/note.txt ~/files-lab/cheat/note-copy.txt` | `cp note.txt note-copy.txt` без `-i` молча затирает уже существующую копию |
| `cp -n` | Копирует, но не заменяет существующий файл | `cp -n ~/files-lab/cheat/note.txt ~/files-lab/cheat/note-copy.txt` | `cp -f` заставляет замену даже если файл защищён от записи |
| `mv` | Переносит или переименовывает | `mv ~/files-lab/cheat/note-copy.txt ~/files-lab/cheat/renamed.txt` | `mv note.txt /tmp` без проверки уносит файл из рабочего каталога |
| `ln -s` | Делает символическую ссылку: в ней хранится путь, не содержимое | `ln -s note.txt ~/files-lab/cheat/note-link.txt` | `ln -sf` заменяет уже существующую ссылку без вопроса |
| `ls []` | Маска: один символ из набора в скобках | `ls ~/files-lab/cheat/photo-00[1-2].jpg` | `rm photo-00[1-5].jpg` удалит все совпадения, если заранее не посмотреть `ls` |
| `rm` | Удаляет файлы сразу, без корзины | `ls ~/files-lab/inbox/*.bak`, затем `rm -v *.bak` | `rm * .bak` — пробел перед `.bak` удаляет все файлы каталога |
| `rmdir` | Удаляет только пустой каталог | `rmdir ~/files-lab/cheat/sub` | `rmdir` не удаляет каталог с файлами; `rm -rf /` опасен тем, что стирает дерево без вопросов |
| `find` | Ищет по дереву каталогов | `find ~/files-lab/cheat -name "*.txt"` | `find / -name "*.txt"` без ограничения каталога обходит всю систему |
| `find -delete` | Удаляет то, что нашёл `find` | `find ~/files-lab/cheat -name junk.tmp -delete` после просмотра списка | `-delete` до проверки сотрёт лишнее; его нельзя ставить раньше условий |
| `locate` | Ищет путь по базе, а не по живому диску | `locate os-release \| head -1` | `locate` после удаления всё ещё показывает старый путь, пока не сделать `updatedb` |
| `man -k` | Ищет страницы справки по ключевому слову | `man -k ls \| head -2` | Путать с `man ls`: `-k` ищет описания, а не открывает страницу команды |
| `type` / `which` | Показывают, откуда берётся имя команды | `type ls` и `which ls` | `which` не видит встроенные команды оболочки так, как `type` |
