## задание 1
* Настольная → это стандартная ОС для персональных компьютеров → в окне «Характеристики Windows» на моём ПК указан выпуск Windows 10 Pro.
* Многозадачная → система способна выполнять множество процессов и служб одновременно → в Диспетчере задач видно, что параллельно работают Yandex, Visual Studio Code, Discord, Steam, Telegram, Microsoft Word и системные процессы.
* Многопользовательская → архитектура системы позволяет создавать несколько профилей с разделением прав → хотя на моём ПК сейчас используется только один пользователь, система поддерживает добавление других учетных записей в параметрах.
* Комбинированный → ОС предоставляет как графическую оболочку (GUI), так и интерфейс командной строки (CLI) → я взаимодействую с окнами и курсором в интерфейсе, но также в системе присутствует командная строка.
* Общего назначения → система не ограничена узкой промышленной задачей и решает широкий спектр задач → на моем ПК одновременно запущены приложения для разработки (VS Code), игр (Steam), общения (Discord) и работы с документами (Word).
* Сетевая → система имеет встроенные сетевые возможности и средства маршрутизации → мой ПК подключен к локальной сети и интернету, обмениваясь данными исключительно через LAN-подключение.

## задание 2
| ОС | Где применяется | Тип по назначению | Многозадачность | Интерфейс | Ключевое отличие |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Windows 10 Pro** | Домашние ПК, ноутбуки, корпоративные рабочие станции | Настольная (общего назначения) | Многозадачная | Графический (основной) + командная строка | Закрытый исходный код, максимальная совместимость с коммерческим ПО и играми. |
| **Arch Linux** | ПК продвинутых пользователей, серверы | Настольная / Серверная | Многозадачная | Изначально командный (GUI устанавливается пользователем) | Плавающий релиз (rolling release), ОС собирается пользователем с нуля «как конструктор» (философия KISS). |
| **Android** | Смартфоны, планшеты, смарт-ТВ, мультимедиа авто | Мобильная | Многозадачная (со строгим ограничением фона) | Графический (сенсорный) | Оптимизация под сенсорный ввод и жесткая экономия заряда батареи. |
| **FreeRTOS** | Микроконтроллеры, IoT-устройства, датчики, умная бытовая техника | Встроенная / ОС реального времени (RTOS) | Многозадачная (с жесткими приоритетами) | Отсутствует (только программный API для разработчиков) | Гарантированное время отклика (в микросекундах) и работа на устройствах с минимальным объемом памяти. |

**Почему нельзя считать, что все операционные системы предназначены для одних и тех же задач:**

Разные устройства обладают разными аппаратными ресурсами и сценариями использования. Для настольного ПК требуется универсальная система с удобным интерфейсом, способная одновременно запускать ресурсоемкие программы, среды разработки и игры. Мобильные устройства, напротив, требуют жесткого контроля фоновых процессов для экономии заряда батареи и интерфейса. В свою очередь, микроконтроллеру в промышленном датчике вообще не нужен графический интерфейс, зато критически важна гарантированная и мгновенная реакция на аппаратные события. Поэтому архитектура каждой ОС создается под конкретнное устройство.
