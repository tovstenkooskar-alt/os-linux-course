# Учебный репозиторий: Операционные системы (Linux)

**Студент:** Оскар Товстенко, курс 2, группа 9/2-РПО-25/1  
**Репозиторий:** `tovstenkooskar-alt/os-linux-course`

## Назначение репозитория
Данный репозиторий предназначен для контроля версий и централизованного хранения документации, отчетов и практических заданий, выполняемых в рамках учебного курса по изучению операционных систем.

## Цели на курс
1. Детально разобраться во внутреннем устройстве и базовых принципах работы современных операционных систем.
2. Научиться уверенно разворачивать, администрировать и работать с виртуальными машинами.
3. Понять архитектуру ОС, механизмы распределения ресурсов и освоить системный подход к решению задач («как думает ОС»).
4. Получить устойчивые практические навыки работы в консоли и администрирования Linux-сред.

## Структура репозитория
```text
os-linux-course/
├── README.md
├── assets/          — хранит медиафайлы и ассеты, с которыми мы будем работать
│   └── screenshots/ — хранит скриншоты для подтверждения выполнения заданий
├── labs/            — хранит наши лабораторные работы (каждая работа в отдельной подпапке)
├── reports/         — хранит паспорта проектов и Markdown-отчеты (system-passport.md и др.)
└── scripts/         — папка для хранения исполняемых скриптов автоматизации
```

## Правила ведения репозитория
правила ведения: одна работа — отдельная папка, понятные имена файлов, осмысленные коммиты, отсутствие секретов и персональных данных.
