# Инструкция по воспроизведению диагностики системы

Ниже описаны шаги, с помощью которых любой другой студент сможет повторить сбор характеристик ПК и убедиться в их достоверности.

**Шаг 1. Проверка версии операционной системы**
* **какой инструмент открыть** → Утилита `winver`.
* **куда перейти** → Нажать комбинацию клавиш `Win + R`, в появившемся окне «Выполнить» ввести безопасную команду `winver` и нажать Enter.
* **что найти** → Откроется информационное окно «Windows: сведения».
* **как проверить** → Сравнить указанный выпуск (например, Windows 10 Pro) и номер версии/сборки с данными из о системе.

**Шаг 2. Проверка процессора, ОЗУ, видеокарты и статуса виртуализации**
* **какой инструмент открыть** → Диспетчер задач.
* **куда перейти** → Нажать комбинацию клавиш `Ctrl + Shift + Esc`, при необходимости нажать «Подробнее» и перейти на вкладку «Производительность».
* **что найти** → Разделы «ЦП», «Память» и «Графический процессор» (GPU) в левой колонке.
* **как проверить** → 
  * В разделе «ЦП» в правом верхнем углу прочитать точную модель процессора, а внизу справа найти строку «Виртуализация» (должно быть «Включено»).
  * В разделе «Память» в правом верхнем углу посмотреть общий аппаратный объем ОЗУ (например, 32,0 ГБ).
  * В разделе (GPU) в правом верхнем углу посмотреть точное название модели видеокарты. Все полученные данные должны совпадать с менеджером устройств.

**Шаг 3. Комплексная проверка через системную утилиту**
* **какой инструмент открыть** → Сведения о системе (msinfo32).
* **куда перейти** → Нажать Win + R, ввести команду msinfo32 и нажать Enter.
* **что найти** → Откроется окно со сводкой системы. Обратить внимание на центральную панель с элементами и их значениями.
* **как проверить** → Найти строки «Имя ОС», «Процессор» и «Установленная оперативная память (RAM)». Сверить эти значения с теми, что были получены на Шагах 1 и 2 — они должны быть полностью идентичны, что подтверждает правильность собранных данных.
